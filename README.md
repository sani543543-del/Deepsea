# Deep-sea bioluminescence — Remotion (Gradient Fluid)
1. npm install
2. npx remotion studio src/index.ts      (preview, SFX included)
3. npx remotion render src/index.ts Main out/video.mp4 --codec h264 --crf 17
Optional: put the narration at public/voiceover.mp3, then toggle `previewVoiceover` in the Studio Props panel.
SFX are generated by `npm run sfx` (already included in public/sfx).
